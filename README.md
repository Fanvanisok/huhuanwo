# 请以你的名字呼唤我 项目组官网

原生 HTML / CSS / JavaScript 五页静态网站，无需安装依赖、无需构建。直接打开 `index.html` 即可浏览，也可使用任意静态服务器预览。

## 页面

- `index.html` 首页
- `about.html` 概况，含团队简介、发展历程、团队制度、发展规划切换
- `activities.html` 志愿经历，含活动分类筛选
- `organization.html` 组织架构，按要求暂保留待补充
- `contact.html` 联系我们

## 后续替换

- `assets/logo.png`：由用户提供 Logo 裁出标志主体，保留原色。
- `assets/banner.svg`：本地示意插画，可替换为团队实景图。
- `app.js`：页面内容、示例活动、公开联系方式。
- `styles.css`：配色与电脑、手机响应式布局。

团队介绍和制度摘要参考用户所提供文档；活动卡片均为明确标注的示例，不代表已发生的活动报道。没有发布成员个人信息、内部会议安排、虚构统计、虚构联系方式。友情链接与深层详情入口未实现；五页主导航可正常跳转。没有后端、留言收集或报名提交功能。

上线前需核验团队正式名称、服务现状、内容授权、未成年人影像使用许可，并补齐组织架构与公开联系方式。当前为课程设计展示版。
